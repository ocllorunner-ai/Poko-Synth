# ポコシンセ／ポコ鍵盤（Android版）

ブラウザ版の「ポコシンセ」と「ポコ鍵盤」をネイティブのAndroidアプリにしたものです。
1つのプロジェクトから2つのアプリができます。

| フォルダ | アプリ | 中身 |
|---|---|---|
| `synth/` | ポコシンセ | タッチパッド。左右で音程、上下で音量。ポコ付き |
| `keys/` | ポコ鍵盤 | 鍵盤。横向き固定 |
| `audio/` | （共通部品） | 低遅延の音声エンジンとボタン類 |

画面の言葉は端末の言語設定に合わせて、日本語か英語で表示されます。

## GitHubでAPKを作る

1. GitHubにログインし、右上の「＋」→「New repository」で新しいリポジトリを作ります（Privateで構いません）。
2. 「uploading an existing file」を開き、このフォルダの**中身をすべて**ドラッグして「Commit changes」を押します。
   - `.github` フォルダ（名前が「.」で始まる隠しフォルダ）も必ず含めてください。
     Macでは Finder で `Command + Shift + .` を押すと表示されます。
   - うまく入らない場合は、「Add file」→「Create new file」でファイル名に
     `.github/workflows/build.yml` と入力し、このフォルダの同名ファイルの中身を貼り付けて保存してください。
3. リポジトリの「Actions」タブを開くと、ビルドが自動で始まります（5分ほど）。
   始まらない場合は「Build APK」→「Run workflow」を押します。
4. 緑のチェックが付いたら、その実行結果を開き、下の「Artifacts」にある `poko-apks` をダウンロードします。
5. zipを展開すると `PokoSynth.apk` と `PokoKeys.apk` が入っています。

## スマホに入れる

1. APKをスマホに送ります（Googleドライブ、USB、メールなど）。
2. スマホでAPKを開きます。「提供元不明のアプリ」の許可を求められたら、開いたアプリ（ファイルやChromeなど）に許可を出します。
3. 「インストール」を押します。Playプロテクトの警告が出たら「インストールする」を選びます。

ソースを変えてGitHubに上げ直すと、新しいAPKが自動で作られます。署名の鍵（`poko.keystore`）を固定しているので、
新しいAPKは前のアプリに上書きでインストールでき、設定も残ります。

## 遅延について

音声はKotlinの `AudioTrack` を低遅延モードで使い、端末本来のサンプリングレートとバッファサイズで鳴らしています。
最初は小さなバッファで始め、音が途切れたときだけ少しずつ大きくするので、ノイズを出さずにその端末で出せる最小に近い遅延になります。
Bluetoothイヤホンでは大きな遅延が出るため、有線イヤホンか本体スピーカーをおすすめします。

## メモ

- `poko.keystore` は個人で使うための署名鍵です（パスワードは `pokopoko`）。Google Playで公開する場合は、自分専用の鍵を作り直してください。
- Android 8.0（API 26）以上で動きます。
- Android Studioでもそのまま開いてビルドできます。
